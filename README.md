# Nissan Leaf Diag

Діагностика Nissan Leaf (ZE0 / AZE0) для Android через ELM327 по Bluetooth Classic.

Версія 0.5.0 — повний інтерфейс замість голого списку кнопок, демо-режим і чесна
діагностика самої шини CAN.

---

## Екрани

| Екран | Що показує |
| --- | --- |
| Підключення | вибір спареного ELM327, стан з'єднання, тест адаптера, розбір помилки CAN |
| Акумулятор | SOC, SOH, Hx, GIDs, Ah, напруга, струм, потужність, 12 В |
| Акумулятор → Комірки | 96 комірок з підсвіткою відхилень, мінімум/максимум/Δ |
| Акумулятор → Температури | датчики батареї зі шкалою |
| Автомобіль | VIN, модель, одометр, швидкість, режим, запас ходу |
| Зарядка | стан зарядки, потужність, лічильники QC та L1/L2 |
| Електронні блоки | 16 блоків Leaf: онлайн-статус, модель, виробник, прошивка |
| Помилки (DTC) | коди з трьох протоколів, стирання за підтвердженням |
| Логування | запис CSV, графік заряду, дамп LBC, список файлів |
| CAN Монітор | сирі кадри шини з фільтром за ID |
| Налаштування | демо, період опитування, одиниці, дозвіл на стирання DTC |
| Про додаток | версія, застереження, джерела протоколу |

## Демо-режим

Вмикається на екрані «Підключення» або в налаштуваннях. Дає повністю заповнений
інтерфейс без адаптера й без машини: 96 комірок, температури, блоки ECU, коди
помилок, кадри CAN. Потрібен для двох речей — подивитися застосунок і перевірити,
що екрани правильно поводяться з даними.

У демо-режимі застосунок **не звертається до адаптера взагалі**.

---

## Якщо адаптер каже CAN ERROR

Це найчастіше питання, і воно не про застосунок.

* **CAN ERROR** — адаптер спробував віддати кадр у шину й не отримав підтвердження
  (ACK). Тобто на шині немає жодного живого вузла. Причини: машина не в READY,
  адаптер не в роз'ємі, несправний клон ELM327.
* **NO DATA** — навпаки, добрий знак: шина жива, просто конкретний блок не
  відповів на цей запит.
* Leaf майже не підтримує стандартні режими OBD, тому `0100` → CAN ERROR
  сам по собі нічого не доводить.

Головний тест — **пасивний перегляд шини**: кнопка «Тест адаптера» слухає шину
1.6 с і рахує кадри. Нуль кадрів + CAN ERROR = шини немає. Кадри є = все гаразд,
далі питання лише до конкретних запитів.

## Звідки беруться дані

Застосунок бере значення з двох різних джерел, і вони різні за надійністю.

**Широкомовні кадри** — машина розсилає їх сама, застосунок лише слухає:

| Кадр | Значення |
| --- | --- |
| `0x55B` | SOC, десяті відсотка |
| `0x5BC` | GIDs |
| `0x5B3` | SOH (оцінка) |
| `0x5C5` | одометр |
| `0x1DB` | струм і напруга пакета |

**Службові запити до LBC** (`79B → 7BB`), багатокадрова відповідь ISO-TP:

| Запит | Значення |
| --- | --- |
| `21 01` | Ah, Hx, напруга пакета |
| `21 02` | напруги 96 комірок |
| `21 04` | температури батареї |

Кожне значення проходить перевірку діапазону: не схоже на правду — поле лишається
порожнім. Порожньо чесніше, ніж красиве сміття.

Зсуви полів у групі `21 01` взяті з відкритих джерел і **ще не звірені на живій
машині**. Для звірки в застосунку є кнопка «Зняти дамп LBC» — вона зберігає сирі
відповіді у файл.

Того, що перевірити нічим, тут просто немає. Напруга 12 В у живому режимі
не показується: єдина відома таблиця для кадру `0x1F2` фізично не здатна дати
13.2 В (її максимум — 12.75 В), тобто вона хибна. У демо-режимі значення є,
бо демо для того й існує.

Докладніше — `docs/DECODERS.md`.

## Безпека

* Усе, що робить застосунок, — читання. Єдиний виняток — стирання кодів
  несправностей, і воно вимкнене за замовчуванням, вмикається в налаштуваннях і
  вимагає підтвердження в діалозі.
* Жодних команд кодування, перепрошивки чи зміни налаштувань блоків немає.
* Файли логів лежать у папці застосунку на телефоні. Нічого нікуди не надсилається.
* Дешевий клон ELM327 на шині машини здатний нашкодити більше, ніж будь-яка
  діагностична програма.

## Збірка

```bash
./gradlew testDebugUnitTest assembleDebug
```

AGP 9.4.0, Gradle 9.6.0 (обгортка в репозиторії), compileSdk 37, JDK 17+.
Докладно — `BUILD.md`.

У репозиторії лежить GitHub Actions workflow `.github/workflows/build-apk.yml`:
кожен push проганяє юніт-тести, збирає debug APK і кладе його в артефакти.

## Що далі

1. Звірити зсуви `21 01` на живій машині за дампом LBC.
2. Лічильники зарядок QC / L1-L2 з тієї ж відповіді.
3. Швидкість, режим селектора й температуру повітря з широкомовних кадрів.
4. Підтримка BLE-адаптерів (LE Link) — зараз лише Bluetooth Classic SPP.
5. Профіль ZE1 (Leaf 40/62 кВт·год) окремо від AZE0.
